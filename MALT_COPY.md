# Malt portfolio copy

## Title
A Searchable WordPress Library for Practical Engineering Knowledge

## Short description
Useful technical guidance becomes difficult to find in an unstructured list. Readers need a focused search experience, clear topic navigation, useful full articles and a simple way to keep resources for later. Editors need content they can maintain without changing the site’s code.

## Project description
Built an original responsive WordPress theme and content plugin around eight original engineering resources. A custom content type makes articles editable in WordPress, with metadata for topic, format and reading time. Full-text search and combined topic filters lead to complete article pages containing workflows and practical checklists. Browser bookmarks create a saved reading list without user accounts. Source code, installable packages, a local WordPress environment and a separate Python runtime are included.

Executed in real WordPress 7.1.2. All 7 WordPress integration checks passed: theme/content count, body-text search, topic filtering, empty state, full article permalink, custom content API and saved-list view. The separate Python runtime passed 5 integration tests covering eight complete articles, search, combined filters, safe output, saved view and missing routes. Browser bookmark interaction is checked separately during screenshot capture.

**Project status:** New independent project created for my own portfolio. The WordPress implementation is functional and verified locally. It is not presented as a past paid client project or a public production deployment.

## What I delivered
- Eight original editable articles across four technical disciplines
- Full-text search, topic filters and useful empty states
- Article permalinks, workflow summaries and practical checklists
- Browser bookmarks and a saved reading list without accounts
